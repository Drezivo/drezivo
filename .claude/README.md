# Root Claude guidance

Read `../ROOT-REPOSITORY-ARCHITECTURE.md` and `../CLAUDE.md` before working in this folder.
The root guide is the source of truth for the five repositories and their ownership boundaries.
Rules here govern cross-repository work; repo-local rules govern implementation details. When a
root rule changes, update the matching file under `.codex/rules/` manually. The utility under
`docs/scripts/` synchronizes the five repository-local mirrors.
