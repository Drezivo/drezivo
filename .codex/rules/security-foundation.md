# Security foundation

Read the private root `SECURITY-FOUNDATION.md` when it is available. It is intentionally ignored by
Git. If it is absent, read the root `SECURITY-FOUNDATION.template.md` and obtain the private guide
before security-sensitive work. It defines the Drezivo baseline for sessions, tenant and branch
authorization, idempotency, risk signals, bot controls, logging, incident response, and suggested
configuration names.
