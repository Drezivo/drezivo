# Obsidian Second Brain

Use a project-only Obsidian vault to connect product, architecture, repositories, decisions,
research, operations, and daily lessons. Markdown is portable, wikilinks make relationships
explicit, JSON Canvas shows system boundaries, and Bases provides metadata views.

The vault is not a production database, secrets store, customer record system, or substitute for
the PRD/TRD/API. Shared hosting requires a private Obsidian Sync vault or private Git repository
with access control and reviewed redaction.
