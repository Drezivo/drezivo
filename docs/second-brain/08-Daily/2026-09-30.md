# Dashboard Overview Data Integration

## Decision and scope

The staff dashboard now has a single read endpoint, `GET /api/v1/dashboard/overview`, for its visible operational cards and tables. It resolves the active tenant/branch from staff context and calculates “today,” upcoming windows, and month comparisons using database time plus the branch timezone. Upcoming fittings cover the remainder of today and the following two branch-local calendar days.

Business performance is presented as completed rental value (excluding deposits), completed-rental count and average, and active new-customer count. It is not accounting revenue or collected-cash reporting. Dashboard issue/readiness queues and quick actions remain separate future work.
