# 2026-10-11

## Confirmed reservation customer snapshot editing

- Reservation Details editing is confirmed-only and changes the selected reservation's customer snapshot (name, phone, email, address), not its shared customer profile or other reservations.
- Date/time, event date, fulfillment/delivery, payment/evidence, schedule/allocation, and custody facts are excluded by the strict API contract.
- The action order is Pick Up → Edit → Cancel where permissions allow; hide the row while the editor is open.
- Canonical PRD/TRD and [[02-Architecture/Customer Address and Social Profile Fields]] now state this boundary. No migration is expected.
